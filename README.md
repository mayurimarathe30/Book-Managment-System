# 📚 Book Management System

A modern and responsive Book Management System built using React.js, Vite, Tailwind CSS, and MockAPI. This application allows users to manage books with full CRUD functionality including adding, editing, deleting, searching, and filtering books.

---

## 🔗 GitHub Repository

(https://github.com/mayurimarathe30/Book-Managment-System.git)

---

## Features

- View all books
- Add new books
- Edit existing books
- Delete books
- Search books by title or author
- Filter books by genre
- Responsive dashboard UI
- API integration using MockAPI
- Loading states and error handling
- Toast notifications
- Modern admin dashboard design

---

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Axios
- React Router DOM
- React Toastify
- MockAPI

## ⚙️ Installation & Setup

### 1 Clone Repository

```bash
git clone <your-github-repo-link>
```

### 2 Open Project Folder

```bash
cd Book-Management-System
```

### 3 Install Dependencies

```bash
npm install
```

### 4 Run Development Server

```bash
npm run dev
```
